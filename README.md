# Chaithanya Vatsa - SAP FICO Consultant Portfolio

A premium, elegant, and professional portfolio website designed for SAP FICO consulting excellence.

## 🎨 Design Features

- **Luxury Color Palette**: Deep navy blue (#0F172A), muted gold (#C5A572), champagne beige (#E4C59E)
- **Glassmorphism Effects**: Modern frosted-glass card designs
- **Smooth Animations**: Framer Motion powered transitions and effects
- **Parallax Scrolling**: Depth-enhanced user experience
- **Responsive Design**: Mobile-first approach for all devices
- **Corporate Precision**: Inspired by top financial and luxury brands

## 🛠️ Tech Stack

- **React 18** - Modern UI library
- **TypeScript** - Type-safe development
- **Vite** - Lightning-fast build tool
- **TailwindCSS** - Utility-first styling
- **Framer Motion** - Professional animations
- **Lucide React** - Premium icon set

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎯 Sections

1. **Hero** - Elegant introduction with animated tagline
2. **Expertise** - SAP FICO core competencies (FI & CO modules)
3. **Impact Metrics** - Quantified professional achievements
4. **About Me** - Strategic vision and professional approach
5. **Projects** - Featured SAP implementations
6. **Certifications** - Professional credentials and qualifications
7. **Contact** - Multiple channels for engagement

## 🚀 Customization

To customize this portfolio for yourself:

1. Update contact information in `src/components/Contact.tsx`
2. Modify projects and certifications data
3. Adjust color scheme in `tailwind.config.js`
4. Replace profile details throughout components
